# 价格不是一个数字

上一课结尾我们留了个伏笔：一根 K 线丢掉了很多细节。这一课就把丢掉的东西捡回来。你会发现，"价格"从来不是单一的数字，而是一组随时间跳动的报价。理解这一点，是从"看图猜涨跌"走向"理解微观结构"的第一步。

## 买价 (Bid) 与卖价 (Ask)

任何时刻，市场上同时存在两类报价：

- **买价 (Bid)**：当前**最高**的买入报价。也就是别人愿意以这个价从你手里把股票买走。
- **卖价 (Ask / Offer)**：当前**最低**的卖出报价。也就是别人愿意以这个价把股票卖给你。

举个例子，A 股票最新报价是 "Bid 100.05 / Ask 100.07"。意思是：

- 如果你**现在就想买**，得付 100.07；
- 如果你**现在就想卖**，只能拿到 100.05。

中间那 0.02 元就是 **价差 (spread)**。新手第一次看到这个结构时常感到困惑：为什么"价格"会有两个？答案就在上一课的提示里——市场不会先有"价格"再有买卖，而是先有"买卖意愿"再撮合出"价格"。Bid 和 Ask 才是原始数据，所谓"最新价"只是最近一次成交的痕迹。

## 价差 (Spread) 是什么？为什么有人愿意付？

价差是市场结构里最重要的一个数字之一。它的定义很直接：

<MathBox>\text{Spread} = P_{\text{ask}} - P_{\text{bid}}</MathBox>

也可以用百分比衡量，叫**相对价差 (relative spread)**：

<MathBox>\text{RelativeSpread} = \frac{P_{\text{ask}} - P_{\text{bid}}}{(P_{\text{ask}} + P_{\text{bid}}) / 2}</MathBox>

谁在赚这个价差？主要是 <Glossary term="market maker">做市商 (market maker)</Glossary>。他们同时挂买单和卖单，不断地以略低的价格买入、再以略高的价格卖出，赚取价差作为提供流动性的报酬。

所以，**价差 = 你为"立刻成交"支付的便利费**。如果你愿意挂限价单慢慢等，可以不付；但只要你想"现在就成交"，价差就是你的成本。

## 订单簿 (Order Book) 直观图示

把所有未成交的买单和卖单按价格排序，就得到 **订单簿 (order book)**。它通常长这样：

```text
        卖单 (Ask side)
价格      数量
100.10    500
100.09    300
100.07    200    <- 最优卖价
-----------------
100.05    400    <- 最优买价
100.04    600
100.02    900
        买单 (Bid side)
```

需要注意三件事：

1. **最优买价 (best bid)** 和 **最优卖价 (best ask)** 永远不会相交——否则它们会立刻撮合掉。
2. 离最优价越远，挂的数量通常越大（深度厚），但成交概率越低。
3. 你下市价单时，本质上是**从最优价开始往簿子里"吃"**，直到吃满你的数量。

## 滑点 (Slippage) — 大单的隐性成本

设想你想买入 1000 股，但最优卖价只挂了 200 股。剩下的 800 股就要从更高的价格档位去吃：

| 档位 | 价格 | 数量 |
|---|---|---|
| 1 | 100.07 | 200 |
| 2 | 100.09 | 300 |
| 3 | 100.10 | 500 |

平均成交价 = (200·100.07 + 300·100.09 + 500·100.10) / 1000 = 100.093

如果你以"现在的最优卖价 100.07"为基准，那么每股多付了约 0.023。这就是 **滑点 (slippage)**。它的一般定义：

<MathBox>\text{Slippage} = \bar{P}_{\text{fill}} - P_{\text{ref}}</MathBox>

其中 $\bar{P}_{\text{fill}}$ 是你这笔单的实际加权平均成交价，$P_{\text{ref}}$ 是参考价（常用下单瞬间的最优卖价或中间价）。

回测时如果只用收盘价模拟成交、忽略滑点，**你的策略收益会被系统性高估**——尤其是高频或者大单策略。

## 流动性的含义

我们把上面这些概念串起来，就能定义 **流动性 (liquidity)**：

> 流动性 = 你能多快、以多接近"公允价"的成本，把一笔指定大小的单子做掉。

流动性高的标的特征：

- 价差小（spread 窄）；
- 订单簿深（每档挂单量大）；
- 大单的滑点小；
- 全天成交量大、参与者多样。

反之，小盘股、冷门 ETF、深夜的外汇盘、刚上市的新股，流动性都偏差。

学术上还有一个更精细的指标，叫 **有效价差 (effective spread)**，用来衡量"实际成交成本"而不是"挂单价差"。它的定义是：

<MathBox>\text{EffectiveSpread} = 2 \cdot |P_{\text{trade}} - P_{\text{mid}}|</MathBox>

其中 $P_{\text{trade}}$ 是你的实际成交价，$P_{\text{mid}} = (P_{\text{bid}} + P_{\text{ask}}) / 2$ 是下单瞬间的中间价。当你吃单很多时，有效价差通常远大于"显示价差"——这部分多出来的成本就是流动性消耗的代价。

注意：流动性差的标的，**单根 K 线的"价格"可能根本没法以这个价成交**——因为那一刻订单簿上根本没人挂相应数量的单。

一个实操经验：在为新标的设计策略前，先做三件事：

1. 计算它过去 20 个交易日的平均价差，确认你的预期收益**大于价差的若干倍**；
2. 估算典型时段的最优档挂单量，确认你的单笔大小不会显著吃穿一档；
3. 检查每天有没有低成交量时段（如午盘、临近收盘），考虑在这些时段降低下单强度。

这三件事做不到，再漂亮的回测曲线在实盘里都站不住。

这种"流动性预算"思路在量化里非常常见：先估清楚环境，再决定能怎么打。

## 关键要点 + 陷阱

<KeyPoint title="价格的真实结构">任何时刻的"价格"至少包含三个数：bid、ask、last（最近一次成交价）。回测和实盘要分清楚你引用的是哪一个。</KeyPoint>

<Pitfall title="用收盘价直接当成交价做回测">**这是新手最常见的回测偏差。** 收盘价是某一秒的"最后成交价"，它既不是 bid 也不是 ask，更没有包含你这一单的滑点。结果就是模拟收益看起来很美，实盘时被慢慢磨掉几乎所有 alpha。至少要用"下一根 K 线开盘价 + 估算滑点"来近似。</Pitfall>
