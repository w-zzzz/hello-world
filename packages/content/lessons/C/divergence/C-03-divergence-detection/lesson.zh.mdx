# 算法化检测背离

**背离 (divergence)** 就是价格和指标方向不一致：价格创新高，但 RSI 却是更低的高点——价格在上涨，动量却在减弱。在事后画好的图上，背离看起来神乎其神：每一个反转都被提前预警过！但放到一个必须**在摆动点形成的当下就承诺**的回测里，大多数背离都会失败。这一课就是把"图形眼力"转换成一个**不会骗你**的精确算法。

## 四种背离

背离一共四种，由两个二元选择决定：价格在往哪个方向走，以及它预测反转还是延续。

| 名称 | 价格 | 指标 | 含义 |
|---|---|---|---|
| 常规顶背离 | 更高的高点 (HH) | 更低的高点 (LH) | 反转向下 |
| 常规底背离 | 更低的低点 (LL) | 更高的低点 (HL) | 反转向上 |
| 隐藏顶背离 | 更低的高点 (LH) | 更高的高点 (HH) | 延续向下 |
| 隐藏底背离 | 更高的低点 (HL) | 更低的低点 (LL) | 延续向上 |

**常规背离**预测反转——价格创了新极值，但动量没跟上，所以这个极值"靠不住"。**隐藏背离**预测延续——价格在整理，但底层动量还在推，所以原趋势应当恢复。

## 摆动点检测——背离的基础原语

背离本质上是比较两个**摆动点 (swing point)**：两个摆动高点或两个摆动低点。所以在检测背离之前，你必须先检测摆动点。

经典算法用一个 $k$ 根 K 线的窗口：

$$
\text{SwingHigh}(t) = \begin{cases} \text{true} & \text{若 } h_t \geq h_i \text{ 对所有 } i \in [t-k, t+k] \\ \text{false} & \text{否则} \end{cases}
$$

也就是说：$t$ 时刻是摆动高点，意味着它的高价不低于前 $k$ 根、也不低于后 $k$ 根的高价。

**"以及后面 $k$ 根"** 这句话是关键。要确认 $t$ 时刻的摆动高点，必须等到 $t+k$ 时刻才能下结论。**实时算法在 $t+k$ 根 K 线出现之前，根本无法确认 $t$ 时刻的摆动点。** 在已结束的图上一看到就把摆动点标在 $t$ 处，是伪装得很好的前视偏差。

所以诚实的伪代码长这样：

```python
def swing_high(highs, k):
    """在索引 t 处标记摆动高点，确认时间是 t+k。"""
    n = len(highs)
    swings = [None] * n  # 确认时刻 -> 摆动索引
    for t in range(k, n - k):
        window = highs[t - k : t + k + 1]
        if highs[t] == max(window):
            swings[t + k] = t  # 在 t+k 确认
    return swings

def detect_regular_bearish(price_swings, indicator, t):
    """在 t 时刻，查看最近两个已确认的摆动高点。"""
    confirmed = [s for s in price_swings[: t + 1] if s is not None]
    if len(confirmed) < 2:
        return False
    s1, s2 = confirmed[-2], confirmed[-1]
    price_hh = price[s2] > price[s1]
    indicator_lh = indicator[s2] < indicator[s1]
    return price_hh and indicator_lh
```

注意两点。第一，$t$ 遍历的是**确认时间**而不是摆动时间——位于 $s$ 的摆动点要到 $s+k$ 才可用。第二，背离信号最早只能在摆动形成之后 $k$ 根触发。**这段延迟是不作弊的代价。**

## 事后视角和真实交易的鸿沟

任何用过背离交易的人最终都会用真金白银学到这一句话：

> 已结束的图上画出的背离命中率是 100%——因为你只会画那些"管用"的。

你的眼睛会自动挑出那些事后看正好是转折点的摆动；会自动忽略那些一样明显的"摆动"——因为价格继续走了，它们看起来已经不像摆动了。**确认偏误是图形分析美学的结构性问题。**

真正的算法检测器必须在 $k$ 根窗口闭合的那一刻把摆动点"提交"出去，提交后不能反悔。所以它记录的是**所有摆动**，包括那些事后看只是上行途中的小起伏。算法跑出来的背离数量远多于你肉眼看到的——而胜率远低于"教科书上每个背离都管用"的印象。

一个有用的角度：背离是一个**先验 (prior)**，不是结论。在某些市场、某些时候，它让反转概率比无条件基础率略高一点。所以在用它下注之前，要把它和共振（上一课）以及市场状态过滤组合起来。

## $k$ 该取多少？

窗口大小 $k$ 决定你的摆动点噪声水平：

- **小 $k$（如 2-3）：** 摆动多、噪声大、延迟小。你会在毫无意义的微小起伏之间检测出"背离"。
- **大 $k$（如 10-20）：** 摆动少、结构更有意义、延迟大。背离信号在摆动形成之后 10-20 根 K 线才触发——可能已经太晚。

日线上 $k = 5$ 是一个合理的默认值。日内更短周期相应缩小，让你关心的"结构尺度"还看得见。这里没有干净的理论，只能在样本外做参数扫描，确认结果不是对 $k$ 的精确值刀刃般敏感。

<Pitfall title="事后画出来的背离">
教科书图上每一个背离都"管用"，因为那是有人事后画上去的。实时算法必须在 $k$ 根窗口闭合时把摆动点定下来——一旦定下来，那些**没有引发反转**的摆动也必须计入统计。绝大多数算法检测的背离都失败。如果你的策略假设了教科书命中率，实盘表现会让你大跌眼镜。**回测必须用诚实的摆动确认，绝不能用在历史图上目测的摆动。**
</Pitfall>

<KeyPoint title="摆动检测才是难点">
背离不过是"比较价格的两个摆动和指标的两个摆动"。真正的工作量在诚实的摆动检测上——而诚实意味着必须等 $k$ 根 K 线才能确认。任何"在确认窗口闭合之前就检出"的背离都是在读未来，它的回测纯属幻觉。
</KeyPoint>
