# 索提诺比率与卡玛比率

上一课的夏普比率有个被批评已久的缺点：它把上行波动和下行波动一视同仁地塞进分母。可作为交易者，你巴不得上行波动越多越好——惩罚它毫无道理。索提诺比率（Sortino）和卡玛比率（Calmar）正是为修正这个直觉而生：前者只惩罚下行波动，后者用最大回撤替代波动率。这一课讲清楚两者的定义、与夏普的区别，以及一个隐蔽的参数陷阱。

## 索提诺比率：只看下行

索提诺比率把夏普分母里的总标准差换成「下行偏差」$\sigma_d$——只统计跌破某个目标收益（MAR, Minimum Acceptable Return）的那些收益的离散程度：

$$
\mathrm{Sortino} = \frac{E[r] - \mathrm{MAR}}{\sigma_d}, \quad
\sigma_d = \sqrt{\frac{1}{N}\sum_{t}\min(r_t - \mathrm{MAR},\, 0)^2}
$$

注意 $\sigma_d$ 里只对「低于 MAR」的部分平方求和，高于 MAR 的收益记为 0、不计入惩罚。MAR 常取 0 或无风险利率。直觉上，索提诺奖励「上行波动大、下行波动小」的策略——这正是大多数人想要的「收益不对称」。

## 卡玛比率：用回撤当分母

卡玛比率换了一种风险定义——直接用最大回撤的绝对值：

$$
\mathrm{Calmar} = \frac{\text{年化收益率}}{\lvert \mathrm{MDD} \rvert}
$$

比如年化 24%、最大回撤 −30%，卡玛 = 0.24/0.30 = 0.8。它回答的是「我承受的最痛一刀，换来了多少年化回报」，对真实账户的持有体验非常贴近。卡玛通常基于约 3 年数据计算。

<KeyPoint title="三个比率的分母不同">夏普用总波动率，索提诺用下行偏差，卡玛用最大回撤。分子大同小异（超额/年化收益），真正的区别在「你把什么定义为风险」。看一个策略时，三者结合远胜于盯住任何单一指标。</KeyPoint>

## 对比直觉

考虑两个年化收益相同的策略：A 涨跌都很猛但很少深跌，B 收益平稳但偶尔一次深度回撤。夏普可能给 A 打低分（因为上行波动也算进分母），但索提诺会还 A 一个公道；而卡玛会狠狠惩罚 B 那次深跌。

## 参数陷阱：MAR 的选择

索提诺看似客观，其实藏着一个主观旋钮——目标收益 MAR。MAR 取 0 还是取无风险利率，会显著改变哪些收益被计入「下行」，从而改变 $\sigma_d$ 和最终比率。

<Pitfall title="索提诺的 MAR 阈值会大幅改变结果，必须报告">不同的 MAR 会算出不同的索提诺：把 MAR 设得越低，越少的收益被判为「下行」，下行偏差越小，比率越好看。这给了粉饰业绩的空间——有人会偷偷用一个极低的 MAR 把索提诺做高。因此报告索提诺时，必须明确写出所用的 MAR（以及计算频率），否则这个数字无法被复现或比较。同理，卡玛依赖最大回撤，也继承了 MDD 的样本长度依赖问题。</Pitfall>
