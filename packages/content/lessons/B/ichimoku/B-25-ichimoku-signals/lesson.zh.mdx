# 一目均衡表的交易信号：TK 交叉、Kumo 突破、Chikou clear

上一课的五线图描述的是**状态**，这一课我们关注**转换事件**——传统日本交易者用它来触发入场的几个经典信号。一共三个：TK 交叉、价格穿云、Kumo 翻转（twist）。任何一个单独拿出来都没有 edge；真正的 edge——如果存在的话——来自它们之间的**共振（confluence）**。

## 信号一：TK 交叉

**TK 交叉**指 Tenkan 穿越 Kijun。由于 Tenkan 是 9 周期、Kijun 是 26 周期，这在结构上和「快慢均线交叉」非常相似：

$$
\mathrm{TK\ cross}_t = \mathrm{sign}\!\left( \mathrm{Tenkan}_t - \mathrm{Kijun}_t \right) \neq \mathrm{sign}\!\left( \mathrm{Tenkan}_{t-1} - \mathrm{Kijun}_{t-1} \right)
$$

约定：

- **多头 TK 交叉：** Tenkan 上穿 Kijun。
- **空头 TK 交叉：** Tenkan 下穿 Kijun。

细田按交叉位置给信号分级：

- **强信号：** 多头交叉发生在**云上方**，空头交叉发生在**云下方**。
- **中性信号：** 交叉发生在**云内**。
- **弱信号：** 多头交叉发生在云下方，空头交叉发生在云上方——也就是逆 regime。

## 信号二：价格穿云突破

**Kumo 突破**指收盘价穿越云的上沿或下沿：

- **多头突破：** 收盘价站上云顶（Senkou A 与 B 的较大者），之前位于云内或云下。
- **空头突破：** 收盘价跌穿云底（Senkou A 与 B 的较小者），之前位于云内或云上。

云的厚度很关键。穿越薄云的突破比穿越厚云更值得相信，因为云本身就代表「聚合后的支撑/阻力」，薄云说明这部分阻力本来就少。

## 信号三：Kumo 翻转（twist）

**Kumo 翻转**指 Senkou A 与 Senkou B 在**前方投影的云**里发生交叉：

$$
\mathrm{Twist}_t \iff \mathrm{sign}\!\left( \mathrm{SenkouA}_t - \mathrm{SenkouB}_t \right) \neq \mathrm{sign}\!\left( \mathrm{SenkouA}_{t-1} - \mathrm{SenkouB}_{t-1} \right)
$$

由于这两条线在图上都位于当前 K 线的右侧 26 根处，**翻转你能提前看到**——云先变窄、然后掐尖、再换色。交易者把它解读为 regime 切换：图右侧那片云在事先告诉你，未来一段时间趋势方向会反转。

## 共振：Chikou clear 与完整形态

一个纯粹的 Ichimoku 多头形态需要四个条件同时满足：

1. 出现多头 TK 交叉。
2. 价格站在云上方。
3. 前方的云是多头（绿色）。
4. **Chikou clear** —— Chikou（今天的收盘画到 26 根之前）位于 26 根之前的价格区域**上方**，且中间没有 K 线遮挡。

Chikou clear 是大部分交易者会跳过、但偏偏最有用的一条。它在问：**今天的收盘是不是比一个月前更好？** 如果 Chikou 埋在上个月的 K 线里面，那么你看到的「多头突破」其实是在向你能用眼睛看到的供给区里冲，胜算明显下降。

## 与普通均线交叉的对比

裸的 TK 交叉，在大部分权益类回测里，**略弱于** EMA(9)/EMA(26) 交叉。原因在于构造方式：Tenkan 和 Kijun 用的是最高最低的中点，而非收盘价。中点更平滑，但对单根 K 线影线更敏感。所以在公平对比下：

- 单 TK 交叉：和快慢均线交叉接近，略弱。
- TK 交叉 + 云过滤：明显更好，因为云过滤了逆 regime 的交叉。
- TK 交叉 + 云 + Chikou clear：命中率更高，频率更低。

要记住的是一个结构性结论：**交叉本身没有任何 Ichimoku 独有的 edge**——它只是带了几步包装的均线交叉。真正的 edge 来自**过滤栈**。

<Pitfall title="把 TK 交叉当作信号">
裸的 TK 交叉本身不是 Ichimoku 信号——它是用中点替代收盘价的均线交叉。细田的本意是：交叉只是触发器，必须配合云和 Chikou 一起确认才下手。只靠 TK 交叉开仓的策略，其表现和带噪声的快慢均线交叉几乎一致，等于把整套系统的概念性优势丢掉了。如果你把云和 Chikou 这两条限制都去掉，回测结果没有明显变差——那你做的根本不是 Ichimoku。
</Pitfall>

<KeyPoint title="信号是事件，云是过滤器">
TK 交叉、Kumo 突破、Kumo 翻转是 Ichimoku 三大经典事件。edge 来自共振：多头事件 + 价格在云上方 + 前方多头云 + Chikou clear。任意去掉一条，你就退回到一个边际收益接近 0 的均线系统。
</KeyPoint>
