If you can derive backpropagation, you can read every modern deep-learning
paper. If you can't, you'll spend a lot of debugging time confused about why
your loss is NaN.

This is the *one* algorithm to internalize.

## What an MLP actually is

A multilayer perceptron is a stack of linear maps with pointwise nonlinearities
in between. For one hidden layer:

$$
h = \sigma(W_1 x + b_1), \quad \hat{y} = W_2 h + b_2
$$

The nonlinearity $\sigma$ is what makes an MLP more than a fancy linear
regression. Without it, the composition $W_2(W_1 x + b_1) + b_2$ collapses to
another affine map.

<Callout variant="info" title="Universal approximation, soberly">
A wide enough one-hidden-layer MLP can approximate any continuous function on a
compact set arbitrarily well. This is mostly an *existence* result. It says
nothing about how to *find* such a network with gradient descent on finite
data — which is the actual hard problem.
</Callout>

## The computational graph

Every neural network is a directed acyclic graph of tensor operations:
multiplications, additions, activations, reductions. The forward pass evaluates
the graph from inputs to loss. The backward pass evaluates the gradient of the
loss with respect to every parameter by walking the graph in reverse.

<Embed viz="backprop-stepper" />

The key insight: each operation knows its **local Jacobian**. To compute the
gradient with respect to any parameter, you don't need to know the rest of the
graph — just multiply your local Jacobian by the gradient flowing in from
downstream.

## The chain rule, vectorized

Suppose your loss is $L = g(f(x))$ where $f$ produces a vector $z = f(x)$ and
$g$ produces a scalar $L = g(z)$. The gradient with respect to $x$ is

$$
\frac{\partial L}{\partial x} = \frac{\partial L}{\partial z} \frac{\partial z}{\partial x}
= \nabla_z L \cdot J_f
$$

where $J_f$ is the Jacobian of $f$ at $x$. Reverse-mode autodiff computes
$\nabla_x L$ as a series of vector–Jacobian products (VJPs), each costing about
the same as the corresponding forward operation. The total cost of the backward
pass is at most a constant times the cost of the forward pass.

## A two-layer worked example

```python
import numpy as np

# forward
def forward(x, W1, b1, W2, b2, y):
    z1 = x @ W1 + b1            # (B, H)
    h  = np.maximum(0, z1)      # ReLU
    z2 = h @ W2 + b2            # (B, C)
    p  = np.exp(z2 - z2.max(axis=-1, keepdims=True))
    p /= p.sum(axis=-1, keepdims=True)              # softmax
    L  = -np.log(p[np.arange(len(y)), y]).mean()    # cross-entropy
    cache = (x, z1, h, p, y)
    return L, cache

# backward
def backward(cache, W1, W2):
    x, z1, h, p, y = cache
    B = len(y)
    dz2 = p.copy()
    dz2[np.arange(B), y] -= 1
    dz2 /= B                                 # (B, C)
    dW2 = h.T @ dz2                          # (H, C)
    db2 = dz2.sum(axis=0)
    dh  = dz2 @ W2.T                         # (B, H)
    dz1 = dh * (z1 > 0)                      # ReLU derivative
    dW1 = x.T @ dz1
    db1 = dz1.sum(axis=0)
    return dW1, db1, dW2, db2
```

You will rarely write this by hand again — autograd does it for you — but
*reading* this snippet should feel like reading the gradient formulas of a
physical system. Each line is a Jacobian multiplied by an upstream gradient.

## What goes wrong, and why

The two failure modes that make backprop hard:

1. **Vanishing gradients.** Stacking saturating nonlinearities like sigmoid or
   tanh causes gradients to shrink exponentially with depth. Solutions: ReLU
   (active units pass gradient unchanged), residual connections (additive
   identity path), better initialization (Glorot, He), normalization (BatchNorm,
   LayerNorm).

2. **Exploding gradients.** Recurrent networks and very deep stacks can amplify
   gradients similarly. Solutions: gradient clipping, weight decay, careful
   initialization, architectural changes (LSTM gates, attention).

<Callout variant="warning" title="Practical bug-hunt checklist">
NaN loss? In order: (1) check for $\log 0$ in cross-entropy — add `eps`; (2)
check learning rate is not too large; (3) print min/max of activations and
gradients per layer; (4) reduce batch to 1 and look for shape mismatches; (5)
verify your data normalization didn't divide by zero.
</Callout>

## Forward-mode vs reverse-mode: why we always pick reverse

Autodiff comes in two flavors. **Forward-mode** propagates a tangent vector
along with the inputs and recovers a directional derivative in one forward
pass; cost scales with the number of *inputs*. **Reverse-mode** does a
forward pass, caches activations, then sweeps backward to accumulate
gradients; cost scales with the number of *outputs*.

Neural networks have one scalar output (the loss) and millions of input
parameters, so reverse-mode is the unambiguous winner — one backward pass
gives you the gradient with respect to every parameter for the price of
roughly two forward passes. Forward-mode autodiff is still useful in
contexts like Hessian-vector products and certain JAX transformations, but
for "compute $\nabla_\theta L$" it has no role.

This asymmetry is why every training framework — PyTorch's autograd, JAX's
`grad`, TensorFlow's `GradientTape` — defaults to reverse-mode, and why
"backpropagation" and "reverse-mode AD" have become synonyms in practice.

## A linear-algebra view of a layer

A single dense layer $y = Wx$ has gradient
$\partial L/\partial W = (\partial L/\partial y) \, x^\top$ — the outer
product of upstream gradient and input. Stack hundreds of such layers and
the gradient flowing into layer 1 is

$$
\frac{\partial L}{\partial x_0} = \frac{\partial L}{\partial x_T} \prod_{i=1}^{T} J_i
$$

where $J_i$ is the Jacobian of layer $i$. The product of Jacobians is
where everything fragile in deep learning lives. If their singular values
average above 1, the product *explodes*; below 1, it *vanishes*. He / Glorot
initialization is engineered to keep $\mathbb{E}[\|J_i\|_2] \approx 1$ at
init. Normalization layers (BatchNorm, LayerNorm, RMSNorm) maintain this
property *during* training. Residual connections turn the product into
$\prod (I + J_i)$, which behaves like a sum near identity — gradients can no
longer vanish even at hundreds of layers deep.

This is the deep reason the architecture decisions in modern networks are
what they are: every one of them is a Jacobian-product hygiene measure.

## Why this lasts

Modern architectures look very different from a 2-layer MLP — Transformers, MoE
layers, diffusion U-Nets — but the algorithm that trains them is identical.
Every framework you'll use (PyTorch, JAX, MLX) implements reverse-mode
autodiff under the hood. The interface changes; the math stays.

If you can hand-derive the gradient through a softmax + cross-entropy + linear
+ ReLU stack and match what PyTorch's `loss.backward()` produces, you have
fully internalized backprop. That's the test.
