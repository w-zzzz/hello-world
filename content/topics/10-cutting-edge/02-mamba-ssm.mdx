For seven years, attention has been *the* sequence-modeling primitive.
Mamba is the most credible alternative to appear in that time. It is not
a tweak. It rejects the basic premise — that mixing across positions
should be all-pairs — and instead modernizes a much older idea:
state-space models from control theory.

Whether Mamba (or its descendants) replace Transformers, lose to a
hybrid, or remain a niche-but-pivotal tool is genuinely undecided.
Understanding it is non-negotiable.

## Why this matters

Attention is $O(n^2)$ in compute and memory at training, and during
inference its KV cache grows with context length. For very long
sequences (genomics, long-form audio, hours of video, code-bases,
agent-style rollouts), this scaling is a hard wall. Mamba is
$O(n)$ in compute and $O(1)$ in inference state — same expressivity
budget, fundamentally better scaling.

## The state-space recurrence

A continuous-time linear SSM is

$$
h'(t) = A h(t) + B x(t), \qquad y(t) = C h(t)
$$

Discretize with timestep $\Delta$ (zero-order hold gives
$\bar A = \exp(\Delta A)$, $\bar B = (\Delta A)^{-1}(\bar A - I) \cdot \Delta B$),
and you get an RNN:

$$
h_k = \bar A h_{k-1} + \bar B x_k, \qquad y_k = C h_k
$$

The hidden state $h_k \in \mathbb{R}^N$ summarizes everything seen so far.
Inference is $O(1)$ per step in time and memory — like an RNN.

## S4: making it actually work

The naive approach has two problems. First, with arbitrary $A$ the
recurrence is unstable or forgets too fast; HiPPO theory provides a
specific $A$ (a structured matrix) that makes the state hold an
*optimal polynomial approximation* of the input history.

Second, training the recurrence sequentially is slow on GPUs. But
because the discretized SSM is linear and time-invariant, it has an
impulse response

$$
\bar K = (\bar C \bar B, \; \bar C \bar A \bar B, \; \bar C \bar A^2 \bar B, \dots, \bar C \bar A^{n-1} \bar B)
$$

and computing $y$ is a *convolution* $y = \bar K * x$, which an FFT does
in $O(n \log n)$ on the whole sequence in parallel. S4 ties HiPPO
initialization to a fast convolutional training path. Same model;
two efficient views.

<Callout variant="insight" title="The big idea of structured SSMs">
Linearity gives you free parallelism via convolution at training. Time-
invariance gives you HiPPO-style theoretical foundations. Together they
produce a model that trains in parallel and runs as a tiny RNN at
inference. The cost is content-blindness.
</Callout>

## Why selectivity matters

S4 mixes information using the *same* $A, B, C$ for every token. This is
fine for signals (audio, time-series) but disastrous for language: the
right thing to remember depends entirely on what was just said. Attention
gets this for free — its weights are dynamic functions of the input.

Mamba's contribution is **selective SSM**: make $\Delta, B, C$
input-dependent.

$$
\Delta_t = \mathrm{softplus}(W_\Delta x_t), \quad B_t = W_B x_t, \quad C_t = W_C x_t
$$

Now the recurrence

$$
h_t = \bar A_t h_{t-1} + \bar B_t x_t
$$

can decide, per token, how much to keep, what to absorb, and what to
ignore. Set $\Delta_t \to 0$ and the state is preserved (memory). Set
$\Delta_t \to \infty$ and the state resets (forgetting). This recovers
the *gate* of an LSTM, in a much cleaner mathematical frame.

The cost: time-varying parameters break the LTI convolution trick. There
is no single impulse response. So Mamba pays for selectivity with a
*sequential* recurrence — but uses a **hardware-aware parallel scan**
that runs the recurrence in SRAM with $O(n)$ work and good GPU
utilization.

## A minimal selective SSM step

```python
import torch

def selective_scan(x, A_log, B, C, dt):
    # x: (B, L, D), A_log: (D, N), B,C: (B, L, N), dt: (B, L, D)
    A = -torch.exp(A_log)                        # stable, negative-real eigenvalues
    dA = torch.exp(dt[..., None] * A)            # (B, L, D, N) discretized A
    dB = dt[..., None] * B[:, :, None, :]        # discretized B
    h = torch.zeros(*x.shape[:1], x.shape[-1], A.shape[-1], device=x.device)
    ys = []
    for t in range(x.shape[1]):
        h = dA[:, t] * h + dB[:, t] * x[:, t, :, None]
        ys.append((h * C[:, t, None, :]).sum(-1))
    return torch.stack(ys, dim=1)
```

The reference Mamba kernel is much more careful — fused, in SRAM, scanned
with Blelloch's parallel-prefix algorithm — but this captures the math.

## Mamba-2 and SSD

Mamba-2 (Dao & Gu, 2024) introduces the **structured state-space
duality** (SSD): a class of attention with a special "1-semiseparable"
mask is *equivalent* to a class of selective SSMs. This unifies two
families that looked unrelated and lets you implement an SSM as a giant
matmul (good for tensor cores) or as a scan (good for memory).

Practically, SSD blocks are 2–8× faster than Mamba-1 at the same
quality. Most modern hybrids — Jamba, Zamba, Samba — use Mamba-2-style
blocks.

## Where Mamba wins, where it loses

Empirically, pure Mamba is competitive with same-size Transformers on
language modeling and clearly better on very long-context tasks
(genomics, audio, video). It struggles on tasks that require *exact
retrieval* across a long context — copying a token from 5000 positions
back, in-context learning that demands precise attention to specific
locations. The reason is intuitive: a fixed-size hidden state is a
lossy summary of the past, while attention has direct random access.

The current consensus, embodied by Jamba and Zamba, is **hybrid**: most
layers Mamba, a few layers attention. The attention layers handle
retrieval; the Mamba layers carry long-range structure cheaply.

<Callout variant="warning" title="Don't confuse linear time with linear quality">
Mamba is linear in compute, not in capability. There is a real
expressivity gap on retrieval-heavy tasks; it is not closed by simply
scaling. Treat hybrids as the default until evidence accumulates either
way.
</Callout>

## Open frontiers

- **Mamba + MoE**: Jamba combines both. The interactions between
  selective-state and sparse experts are early-days.
- **Long-context training**: SSMs are the most natural fit for >1M
  tokens. The empirical evidence is mounting.
- **In-context learning** in SSMs: still poorly understood relative to
  Transformers; circuits-style interpretability is just starting.

## What to read next
