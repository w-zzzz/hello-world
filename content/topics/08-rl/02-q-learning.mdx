Value iteration assumed you knew the transition dynamics $P$. In real
problems you don't. Q-learning is the temporal-difference algorithm that
learns the optimal action-value function from sampled transitions alone —
no model required. It scales (with neural function approximation) all the
way up to Atari, robotics, and chip placement.

## Why this matters

This is the first algorithm in the curriculum that *doesn't* assume access
to the environment's internals. You only see $(s, a, r, s')$ tuples. From
that you should be able to learn the optimal policy. The fact that this is
even possible — and that it works without a model — is one of RL's foundational
achievements.

## Temporal-difference learning

Suppose you observe a transition $(s_t, a_t, r_t, s_{t+1})$ while following
some policy. The Bellman equation says

$$
Q^*(s_t, a_t) = \mathbb{E}\!\left[r_t + \gamma \max_{a'} Q^*(s_{t+1}, a')\right]
$$

We don't know the expectation, but we have one sample of it. **TD(0)** uses
that sample as a noisy regression target and updates $Q$ a small step toward
it:

$$
Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha \big[ \underbrace{r_t + \gamma \max_{a'} Q(s_{t+1}, a')}_{\text{TD target}} - Q(s_t, a_t) \big]
$$

The bracketed quantity is the **TD error**. It is the difference between
where the value estimate currently is and where one step of bootstrapped
evidence says it should be. Across many transitions, these stochastic
updates converge (for tabular Q with appropriate $\alpha$ schedules) to
$Q^*$.

## On-policy vs off-policy

This is the cleanest dichotomy in RL.

- **SARSA** (on-policy) uses the action *actually taken* by the behavior
  policy: $r + \gamma Q(s', a')$ where $a' \sim \pi(s')$. It learns the
  value of the policy you are currently following.

- **Q-learning** (off-policy) uses the *greedy* action: $r + \gamma \max_{a'}
  Q(s', a')$. It learns the value of the optimal greedy policy regardless
  of how the data was collected.

The off-policy property is enormously useful. It lets you reuse old data
(replay buffers), learn from demonstrations, and explore aggressively
without biasing the value estimate.

```python
import numpy as np

def q_learning_episode(env, Q, alpha=0.1, gamma=0.99, eps=0.1):
    s, _ = env.reset()
    done = False
    while not done:
        # epsilon-greedy behavior policy
        a = np.random.randint(env.action_space.n) if np.random.rand() < eps \
            else int(np.argmax(Q[s]))
        s_next, r, terminated, truncated, _ = env.step(a)
        target = r + (0 if terminated else gamma * np.max(Q[s_next]))
        Q[s, a] += alpha * (target - Q[s, a])
        s, done = s_next, terminated or truncated
    return Q
```

## Deep Q-Networks

Tabular Q is hopeless when $|\mathcal{S}|$ is large (Atari pixels, continuous
robot states). The fix is to parameterize $Q_\theta(s, a)$ with a neural
network and do gradient descent on the squared TD error:

$$
\mathcal{L}(\theta) = \mathbb{E}_{(s, a, r, s') \sim \mathcal{D}} \!\left[ \big(r + \gamma \max_{a'} Q_{\theta^-}(s', a') - Q_\theta(s, a)\big)^2 \right]
$$

Two stabilizers from the original DQN paper made this practical:

1. **Replay buffer** $\mathcal{D}$ — store transitions, sample minibatches.
   Decorrelates updates and reuses experience.
2. **Target network** $Q_{\theta^-}$ — a slow-moving copy of $\theta$. Used
   only to compute the TD target. Without this, the target moves whenever
   the parameters move and training diverges.

## What goes wrong, and what to know

<Callout variant="warning" title="The deadly triad">
Sutton named the combination of (1) function approximation, (2) bootstrapping,
and (3) off-policy learning the *deadly triad*: any two are fine, all three
together can diverge. DQN works in practice through the replay buffer,
target network, and aggressive clipping — but it is not theoretically
guaranteed to converge, and it sometimes doesn't.
</Callout>

Modern improvements (Double DQN, dueling networks, prioritized replay,
distributional RL, n-step returns, noisy nets) are all small fixes to
specific failure modes. Rainbow combines them and remains a strong baseline
on discrete-action benchmarks. For continuous actions, the natural
generalizations are DDPG, TD3, and SAC — value-based methods become trickier
when $\max_a Q(s, a)$ is no longer a finite max.

## Why TD remains foundational

Q-learning is the first algorithm where you *learn from one transition*.
Every modern RL system you'll see — replay-buffer based, off-policy, sample
efficient — owes its inheritance here. Even on-policy actor–critic methods
share the bootstrapping trick: the critic is essentially a TD target
generator for the actor.

If MDPs are the language and Bellman is the grammar, TD learning is the
first complete sentence you learn to write.
