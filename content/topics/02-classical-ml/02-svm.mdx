For a decade, the support vector machine was the model to beat on almost
every supervised learning benchmark. Deep learning eventually displaced it
on perception tasks, but SVMs remain a beautifully principled algorithm —
and the ideas behind them (margin, duality, kernels) keep showing up in
modern ML, from contrastive learning to neural tangent kernels.

If you understand SVMs, you understand a lot of *why* deep learning works
when it does.

## Why this matters

Three reasons SVMs still earn space in your head:

1. **Margin maximization** is the cleanest formal connection between
   geometry and generalization. Vapnik's classical bounds say wider margins
   imply tighter test error — this idea echoes through modern theory
   (NTK, double descent, flat minima).
2. **The kernel trick** is the cleanest example of "compute in an implicit
   feature space" — an idea that powers attention (a learned, data-dependent
   kernel), Gaussian processes, and many graph learning methods.
3. SVMs are still competitive on small, tabular, well-featurized datasets.
   Deep learning hasn't won everywhere.

## Maximum margin classifier

For linearly separable data with labels $y_i \in \{-1, +1\}$, an SVM finds
the hyperplane $w^\top x + b = 0$ that maximizes the **margin** — the
perpendicular distance to the closest training point. Formally:

$$
\min_{w, b} \tfrac{1}{2} \|w\|^2 \quad \text{s.t.} \quad y_i(w^\top x_i + b) \ge 1 \;\;\forall i
$$

The margin is $1 / \|w\|$, so minimizing $\|w\|^2$ maximizes the margin.
This is a convex quadratic program; the global optimum is unique.

The constraint $y_i(w^\top x_i + b) \ge 1$ enforces that all points sit on
the correct side of the margin. Points satisfying it with equality — the
ones touching the margin — are the **support vectors**. Everything else has
zero influence on the solution.

<Callout variant="insight" title="Why the margin matters statistically">
A larger margin means small input perturbations cannot flip the
classification. This robustness translates into tighter generalization
bounds via the VC dimension or, more modernly, Rademacher complexity. It is
the precursor to flat-minima arguments in deep learning.
</Callout>

## Soft-margin SVM

Real data isn't linearly separable. Add slack variables $\xi_i \ge 0$:

$$
\min_{w, b, \xi} \tfrac{1}{2} \|w\|^2 + C \sum_i \xi_i \quad \text{s.t.} \quad y_i(w^\top x_i + b) \ge 1 - \xi_i
$$

$C$ is the regularization knob. Small $C$ favors wider margins and tolerates
more misclassification; large $C$ pushes toward zero training error at the
cost of margin width. Substituting the optimal $\xi_i = \max(0, 1 - y_i (w^\top x_i + b))$
yields the **hinge loss** formulation:

$$
\min_{w, b} \;\; \frac{1}{n} \sum_i \max(0, 1 - y_i(w^\top x_i + b)) + \frac{\lambda}{2}\|w\|^2
$$

which makes SVM training look like any other gradient-based learning
algorithm — and connects it to L2-regularized linear models.

## The dual and the kernel trick

Lagrangian duality of the SVM QP yields:

$$
\max_\alpha \; \sum_i \alpha_i - \tfrac{1}{2} \sum_{i,j} \alpha_i \alpha_j y_i y_j \langle x_i, x_j \rangle \;\; \text{s.t.}\; 0 \le \alpha_i \le C, \; \sum_i \alpha_i y_i = 0
$$

The dual depends on the data only through inner products $\langle x_i, x_j \rangle$.
Replace the inner product with a **kernel** $K(x_i, x_j) = \langle \phi(x_i), \phi(x_j) \rangle$
and you operate in the feature space defined by $\phi$ without ever
materializing $\phi(x)$.

Common kernels:

- **Linear**: $K(x, x') = x^\top x'$.
- **Polynomial**: $K(x, x') = (x^\top x' + c)^d$.
- **RBF (Gaussian)**: $K(x, x') = \exp(-\gamma \|x - x'\|^2)$ — implicit
  feature space is *infinite*-dimensional.

```python
from sklearn.svm import SVC
from sklearn.datasets import make_moons

X, y = make_moons(n_samples=400, noise=0.2, random_state=0)

# Linear kernel will fail — the data isn't linearly separable.
linear = SVC(kernel="linear", C=1.0).fit(X, y)
rbf    = SVC(kernel="rbf", C=1.0, gamma=1.0).fit(X, y)

print("linear acc:", linear.score(X, y))   # ~0.85
print("rbf acc:   ", rbf.score(X, y))      # ~0.99
```

The RBF kernel turns a linearly inseparable two-moons dataset into something
trivially separable in feature space. You never see the feature space; the
kernel handles all of it.

## Why deep learning displaced SVMs (and where SVMs still win)

On raw perception data — images, audio, text — feature engineering matters
more than the classifier on top. SVMs assumed someone else had done that
work; deep nets learn the features end-to-end. That's the whole story of
2012-onward.

But SVMs still win on:

- Small datasets (tens to thousands of examples) with thoughtful features.
- High-dimensional sparse data (text bag-of-words, kernelized).
- Problems where calibrated probabilities matter less than a clean decision
  boundary.

<Callout variant="info" title="The lasting idea">
Attention's $\mathrm{softmax}(QK^\top)$ is, structurally, a *learned,
data-dependent kernel* applied to a value matrix. Modern Transformers are
the kernel trick taken seriously: instead of fixing $K$ a priori, you learn
the projections $W_Q, W_K$ that define it.
</Callout>
